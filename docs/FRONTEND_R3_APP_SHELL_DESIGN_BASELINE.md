# 前端 R3 统一 AppShell 设计基线（FRONTEND_R3_APP_SHELL_DESIGN_BASELINE）

> 日期：2026-10-14 ｜ 状态：R3-0 冻结 ｜ 基线 HEAD：`dac556a`
> 依据：`AppShellCore.vue`（三薄壳内核）+ `workspace-navigation.js`（8 域）+ R3 任务契约。
> 本基线冻结 R3 外壳布局、4+1 导航结构、上下文传递、数据可信度渲染与动作权限渲染规则。R3-1 起所有页面据此实现，不得另造外壳。

## 1. 外壳结构（复用 AppShellCore，不改巨型单组件）

三薄壳继续注入各自导航源与空间强调色，内核 `AppShellCore.vue` 布局冻结：

```
┌────────────────────────────────────────────────────┐
│ 侧栏（64/220px）   品牌点 + ShellSidebar（4+1 导航）  │
├────────────────────────────────────────────────────┤
│ 顶栏 56px   面包屑（domain→title）│ topbar-extras  │
│                ShellTopbar（空间/角色/用户/代客/登出）│
├────────────────────────────────────────────────────┤
│ ShellBanner  代客 > 只读 > partial（优先级冻结）      │
├────────────────────────────────────────────────────┤
│ el-main   <router-view />（页面内容区）              │
└────────────────────────────────────────────────────┘
```

**状态横幅优先级**（NAVIGATION §4，不改）：代客中 > 只读态 > partial 提示；partial 由页面级 `PartialDataBanner` 承接。

**R3 不变项**：空间强调色（`--space-accent-*`）、面包屑渲染、登出清理逻辑（清 token/user/impersonating/Context）、`return_to` 站内校验。

## 2. 4+1 导航结构（替换 8 域 26 项）

`workspace-navigation.js` 由 8 域收敛为 **4 入口 + 全部工具**，侧栏项从 26 → 约 12：

| 入口 | key | 侧栏项 | badge |
|---|---|---|---|
| 我的生意 | `mybiz` | 经营首页 `/app`、我的待办 `/app/tasks` | tasks |
| 我的商品 | `goods` | 商品库、上线中心、合规报告、合规工作台 | approvals |
| 我的订单 | `orders` | 订单工作台、发货备货、售后退款、客户消息 | alerts |
| 我的收益 | `revenue` | 经营总览 BI、真实利润、定价试算 | — |
| 全部工具 | `tools`（抽屉/折叠） | 货源/供应商/匹配/采购、广告、诊断、AI 域、设置 | — |

**规则**：
- 主侧栏只放 4 个高频入口 + 「全部工具」折叠项；低频功能进抽屉。
- 角色过滤统一走 `filter.js`（`buildDomains` / `whitelistForRole`），禁止各树自带过滤。
- 工厂门户、平台控制台仍为独立空间，**不混入商家侧栏**。
- 旧路径 30 条 `legacy-redirects` 不变，深链可达。

**专业用户固定入口**：可固定常用项（localStorage，按 Workspace 隔离），但必须仍过权限过滤。

## 3. 顶栏上下文（始终让用户知道操作作用于哪里）

顶栏必须持续显示（`ShellTopbar` 扩展）：

1. **当前 Workspace / 店铺范围**：切换时取消旧请求、清缓存/所选店铺/批量选择，迟到响应不覆盖新空间。
2. **任务提醒计数**：待我处理 / 等待外部 / 被阻断（小型计数条，非全指标）。
3. **代客身份**：`impersonating` 时 Banner 持续可见，退出代客恢复原身份。
4. **帮助与账号**：登出清理逻辑不变。

## 4. 动作权限渲染（修 E10）

- 每个操作区渲染**按动作的 `allowed_actions`**（后端返回），不再用通用 `canWrite()` 一刀切。
- 403：显示无权限原因 + 申请入口，**不显示为空**。
- 409：保留用户输入，提示冲突来源（版本/状态变化）。
- 超时：提供"查询结果再重试"，不盲目复用失效 revision 或已完成动作。
- 风险动作（发布/删除/资金）只在有实际决策意义时确认，展示对象与影响范围；普通保存不增加多余确认。

## 5. 数据可信度渲染（四轴分离，修 E05/E06）

| 轴 | 组件 | 规则 |
|---|---|---|
| 页面加载 | `SectionState`（11 态） | LOADING/ERROR/READY，文案不页面自写 |
| 业务流程 | `BusinessStatus` | 不单靠颜色，文本 + 图标 |
| 外部平台 | 平台状态标签 | SUBMITTED≠在售，明示 |
| 数据可信度 | 8 类数据标签 | VERIFIED/OBSERVED/ESTIMATED/MISSING/DEMO |

**请求失败不得清空已加载数据**（修 E06）：分区错误、保留已加载、提供重试与更新时间戳。未知用「—/尚未获得」，估算标 ESTIMATED，缺失不当零。

## 6. 对象主详情与上下文传递

- 同一对象**只有一个主详情地址**（`/app/products/:id`、`/app/launch/:id` 等）；卡片/抽屉快速预览，复杂编辑进完整详情。
- 跨页上下文：`product/shop/run/step/return_to` 适用部分；`return_to` 仅站内合法路径，服务端重新验证。
- 素材/合规页从商品或 Launch 进入时**继承**商品、店铺、市场、步骤与返回路径（修 E02 缺 shop_id 静默猜店）。
- 旧链接保留参数与安全返回路径。

## 7. 工作台首屏（修 E07 信息过载）

`WorkspaceHome.vue` 首屏重构：

- **左侧**：「今天需要你处理」1–3 项高优先任务（非 6 屏堆叠）。
- **右侧**：经营阶段 + 唯一推荐入口。
- **上方**：小型计数条（待我处理 / 等待外部 / 被阻断）。
- 排序依据为**时限、风险、责任、阻断程度**，不由 LLM 自由决定。
- 第二屏：进行中上线摘要 + 关键经营指标；AI 已完成作为可展开活动流，不与待办抢主位。
- 趋势图移到经营分析入口，不让新用户先看一屏无数据图表。
- 数据源失败显示未知/部分可用（`PartialBanner`），**不能变成 0**。

## 8. 键盘可达与密度

- 桌面操作合理密度，正文 14px 左右，清晰层级。
- 键盘可完成筛选/表单，焦点可见，图标有文字说明（aria-label）。
- 视口：1440×900、1366×768 完成核心操作；768 与 390 宽度可阅读及处理简单待办，复杂表格合理横滚。
