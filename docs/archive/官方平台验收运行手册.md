# 官方平台验收运行手册

版本：2026-09-22

## 使用原则

- 本地契约测试通过只能标记为 `protocol_ready_unverified`。
- 必须在平台官方 Sandbox、Development Shop 或真实店铺中执行本手册并保存请求追踪 ID、平台资源 ID、时间、操作者和脱敏响应，才能晋升状态。
- 验收使用专用测试 SKU、测试图片和最小库存，不使用真实客户隐私数据。
- 沙箱与生产使用同一业务适配器，仅通过 `ERP_<PLATFORM>_ENV`、凭证和可选 Base URL 切换。
- 任一步出现未知结果时状态为 `uncertain`，先反查平台资源，不直接重放写请求。

## 统一证据要求

每个平台至少保留：

1. OAuth/Token 获取及刷新结果，凭证值必须脱敏。
2. 多页订单完整遍历，包含首尾游标和去重计数。
3. 测试 SKU 的逐请求发布轨迹、平台资源 ID 和最终可见状态。
4. 429、Token 失效、网络超时、部分成功后的恢复轨迹。
5. 同一幂等键重复提交不产生第二个商品、Offer、Feed 或采购单的证明。
6. 规则版本、国家/站点、类目映射和最终审批人。

## 平台验收矩阵

### Shopee

- 完成真实/测试店授权、Token 刷新、分页拉单。
- 完成类目与属性映射、图片上传、商品创建和最终状态反查。
- 验证站点与账号区域一致；当前 SG 验收完成前不得外推其他站点。

### TikTok Shop

- 使用 Partner Center 的 Development Shop 或适用于跨境卖家的测试环境生成测试 Token。
- 验证签名、授权店铺读取、图片上传、Global Product 创建、`global_product_id` 发布和本地商品反查。
- 验证商品进入平台审核时本地只标记 `submitted/processing`，不得提前标记 `published`。
- 沙箱请求必须经过限流器；收到 429 时遵循平台响应退避，不固定假设单一额度。
- 官方参考：[开发店与测试工具](https://partner.tiktokshop.com/docv2/page/seller-developer-onboarding-onepager)、[跨境开发店](https://partner.tiktokshop.com/docv2/page/development-shops-supports-creating-accounts-for-cross-border-shops)、[发布 Global Product](https://partner.tiktokshop.com/docv2/page/publish-global-product-202309)。

### eBay

- 使用 Sandbox 用户授权并确认卖家已加入 Business Policies。
- 预先准备库存地点及 payment、fulfillment、return policy。
- 严格验证 `Inventory Item -> Offer -> Publish Offer -> Get Offer/Listing`。
- 发布必须包含图片、类目、库存地点、价格、数量、三类 policy；任何缺失都应在预检阶段阻断。
- 官方参考：[Inventory API](https://developer.ebay.com/develop/api/sell/inventory_api)、[发布 Offer 必填项](https://www.developer.ebay.com/api-docs/sell/static/inventory/publishing-offers.html)、[Inventory Item 到 Offer](https://developer.ebay.com/api-docs/sell/static/inventory/inventory-item-to-offer.html)。

### Walmart

- 使用 Sandbox Client ID/Secret 获取 OAuth Token。
- 动态 Sandbox 请求带 `WM_SANDBOX: v2`，创建测试商品和订单。
- 验证订单获取、确认、发货、模拟签收完整生命周期。
- Feed 提交后轮询 Feed 和商品级结果；部分失败只恢复失败项。
- 官方参考：[动态 Sandbox 履约验证](https://developer.walmart.com/us-marketplace/docs/validate-order-fulfillment-in-dynamic-sandbox)、[API 集成与环境](https://developer.walmart.com/global-marketplace/docs/api-integration-usage)、[Sandbox 创建订单](https://developer.walmart.com/us-marketplace/reference/createanorder-1)。

### Lazada

- 使用目标国家站点的测试/真实授权，验证签名时间戳、Token 刷新和分页拉单。
- 按站点类目 Schema 生成商品 XML，完成图片迁移、商品创建、状态反查。
- 缺少类目必填属性、品牌资质或站点映射时必须阻断发布。

## 状态晋升门禁

| 当前状态 | 目标状态 | 必需条件 |
|---|---|---|
| `protocol_ready_unverified` | `sandbox_verified` | 官方测试环境完整流程通过，证据齐全且审批通过 |
| `sandbox_verified` | `production_pilot` | 真实店最小流量、可回滚、告警和人工值守 |
| `production_pilot` | `production_verified` | 真实发布、订单、异常恢复和财务对账均有证据 |

任何证据缺失、规则过期、账号区域不匹配或最终状态无法反查，都不得晋升。
