3. 正常链路（售价 99 USD，走真实界面动作）
------------------------------------------------------------
重建副本（SALE_PRICE=99），PRICE_REVIEW = READY。全部动作在浏览器里点出来：

(1) 点 REPORT_PRICE → 动作对话框

  执行动作：REPORT_PRICE
  申报价            （el-input-number，必填）
  币种  必须选择     （el-select，无默认值）
  金额离开币种就是错数，因此不设默认币种
  备注 / 取消 / 执行

  填 99 + 选 USD → 执行 → 时间线：

  阶段 2  平台核价  已完成    依赖：INFORMATION
  阶段 3  价格确认  待执行    依赖：PRICE_REVIEW
  页面无阻断卡片（NO-BLOCKER）

(2) 点 COUNTER_PRICE → 填 109 + USD + 备注「还价 +10」→ 执行

  阶段 3  价格确认  待执行          ← 还价不算谈拢，符合设计

(3) 点 ACCEPT_PRICE → 备注「接受还价后价格」→ 执行

  阶段 3  价格确认  已完成
  阶段 4  在售核验  等待平台反馈

(4) /app/pricing 商品ID=63，点「计算真实利润」：

  轮次  动作      申报价    毛利率  门槛    门禁    决策     时间                 来源

  2     还价      USD 109   89.9%   15.0%   过门槛  未决     2026-11-07 11:09:16  本地轮次
