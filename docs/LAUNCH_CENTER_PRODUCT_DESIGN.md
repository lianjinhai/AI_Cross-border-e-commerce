# Launch Center 产品设计 V2

> 最后更新：2026-10-10。状态：FROZEN_FOR_IMPLEMENTATION；非页面已实现声明。
> DTO/权限/API 唯一依据：`docs/PLATFORM_COMMERCE_WORKFLOW_ARCHITECTURE.md`；状态依据：`docs/PLATFORM_WORKFLOW_STATE_MODEL.md`。

## 1. 用户路径与导航

商品 → 上线中心。保留商品池、候选商品和 Listing；专业合规/定价/供应商继续可直达。新增一个核心入口，不把核价、贴标、证据拆成一级菜单。原 AI 工作流保留批处理与定时任务用途。

选择商品 → 选择当前有权限的销售 Store → 确认市场/店铺类型/经营模式/履约方式 → 预览适用 Profile 和资料缺口 → 启动或打开现有活跃流程。1688 与 source Shop 不出现在销售目标列表。市场缺失提示补渠道资料，不猜国家；Profile 无匹配/冲突给出具体缺项，不随意回退简单流程。

受限/未验证平台可预览并建立显式人工流程，但必须看到 RESTRICTED/UNVERIFIED 和来源说明；测试 Profile 全程显示“本地流程验证，不代表真实平台接入”。不得将测试数据计入经营指标。

## 2. 列表

列：商品、目标平台/Store、国家、履约方式、当前执行/平台状态、完成数/总数、阻断摘要、下一动作、责任人、AI 建议。等待平台显示“等待平台反馈”，不用失败红色替代等待。UNKNOWN 不显示为绿色完成。

筛选：商品/Store/平台/市场/执行状态/责任人/需我处理/历史。默认展示活跃轮次；可展开历史重上线。过滤在服务端 scope 后执行，分页总数也不包含不可见记录。

空状态分开：无商品、无销售店、无适用 Profile、无匹配筛选、没有权限、请求失败。用户可重试请求但不能在未知状态下继续执行旧动作。

## 3. 同一详情页、同一 DTO

顶部：商品、Store、国家、履约方式、Profile 来源、明确的三类状态摘要、进度。左侧流程时间线按 sequence 显示并行分组和依赖标记；右侧为选中任务的说明、要求、缺项、证据、外部反馈、责任人、下一动作。当前焦点不是唯一可操作步骤，“可并行处理”区列出其他 READY 节点。

GUIDED：显示“你的商品已完成 4/9；平台正在核价；当前无需操作；返回核价后将重新计算利润并提醒确认”等业务语言（示例，数值来自 DTO）。保留关键风险、费用、批准提示和证据来源。

PROFESSIONAL：同页展开 raw_status、external_reference/type、mapping_version、Profile hash、同步时间、报价轮次、底价、利润/利润率、成本估算项和证据版本。不是另一套路由、另一套按钮权限或另一套状态。

体验偏好按已冻结方向使用 Workspace 默认 + Membership 覆盖。Launch context API 返回 effective_experience_mode；偏好持久化走已有身份表的增量列与专门服务，不更改冻结 /me 响应字段；无 Membership 的 legacy 使用 Workspace 默认，浏览器临时切换不具有授权含义。

## 4. 任务交互

| 任务 | 交互与明确结果 |
|---|---|
| 资料/平台属性 | 展示缺少字段，进入现有 Product/Listing 编辑页，返回后重新校验版本 |
| 平台提交 | 预检、引用既有发布审批队列；成功提示“已提交，等待平台”，不提示“已在售” |
| 核价 | 同币种显示申报价/平台价/安全价/贡献利润/质量；接受/重报/放弃分别展示影响与批准要求 |
| 备货 | 请求量、批准量、备妥量、供应商/仓库/计划发货日；链接既有采购单，明确“不是销售库存” |
| 合规 | 按市场要求展示必需 Artifact、版本、有效期、来源、核验人；上传后等待核验 |
| 标签 | 展示 manifest 和缺项；生成版本化标签包；缺认证不生成认证标志；打印/贴标另有任务 |
| 实拍 | 上传带来源证据；展示审核结果与驳回原因；补交新版本 |
| 在售核验 | 展示可信 read-back 或独立人工审核材料、时间和对象；普通勾选不可完成 |
| 监控 | Store 真实订单、利润、风险与现有专业页入口；缺关联数据明确不可用 |

动作由后端 available_actions 提供。按钮可展示禁用原因，执行使用 expected_revision 与 Idempotency-Key。409 时保留用户未提交输入、刷新状态并说明变化，不能自动再次确认高风险动作。超时显示“结果待核查”，不诱导连续重发。

## 5. Product 集成与专业页深链

保留 Products 现有列表和详情抽屉；整理概览、货源、销售渠道、上线进度、经营表现、合规、AI 建议、历史。销售渠道按 Store 展示三类状态及当前 Launch 链接，同平台多店不合并为一行。

专业深链携带 launch_id、product_id、listing_id、shop_id、step_code 和 return_to（仅允许站内白名单路径）。目标页服务端仍校验归属，URL 不授予权限。保存后返回该步骤并重新读取状态；禁止从 Listing.platform 查“第一家已授权店铺”代替绑定 Shop。

Asset Center 在 Product 详情和 Launch 任务中共享一个组件：原图/主图/详情图/尺寸图/实拍/视频/条码/标签/合规附件，展示版本、来源、权利、适用市场/平台与授权证明。Label Center 为该组件的标签包视图，不另做重复资料编辑。

## 6. 角色、错误和可访问性

OWNER/OPERATOR 依具体权限执行；READ_ONLY 保留状态/原因，无写按钮；COMPLIANCE 使用合规投影，不收到财务载荷。Factory 通过既有门户看本厂指派步骤，没有卖家完整详情入口，不能跳 URL 读取其他步骤。

错误面板有用户说明、可行动修复和审计编号；凭证、买方 PII 不显示。时间线状态不能只用颜色，需文字与图标；表单有标签/校验消息，键盘可操作；窄屏变为上方步骤选择、下方任务详情，无横向溢出关键按钮。
